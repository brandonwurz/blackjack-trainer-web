# Blackjack Trainer

Single-file blackjack trainer (always 8 decks; S17/H17, DAS and late surrender toggles). Installable PWA.

Live: https://brandonwurz.github.io/blackjack-trainer-web/

Tabs: Learn, Practice, Simulator, Stats, Charts, Levels, and (v3) Speed Run, Count Drills, Index Trainer. See CHANGELOG-v2.md.
