# Blackjack Trainer

Single-file blackjack trainer. Choose 1, 2, 4, 6 or 8 decks (default 8) plus S17/H17, DAS and late surrender. Installable PWA.

Live: https://brandonwurz.github.io/blackjack-trainer-web/

Tabs: Level Path, Free Drill, Speed Run, Count Drills, Index Trainer, Review & Stats, Table Simulator, Bankroll Lab, Game Scorer, Strategy Charts. See CHANGELOG-v2.md.
